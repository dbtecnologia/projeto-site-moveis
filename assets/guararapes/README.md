# Padrões Guararapes

As miniaturas `.webp` desta pasta foram geradas a partir das fotografias oficiais das páginas de produto Guararapes indicadas em `guararapes-catalog.js`.

Fonte oficial para downloads e texturas: https://www.guararapes.com.br/downloads/

As páginas oficiais recomendam validar a escolha pela amostra física. A autorização específica para uso comercial das imagens em uma vitrine própria não foi encontrada na documentação pública consultada; confirmar com a Guararapes antes da publicação comercial definitiva.
